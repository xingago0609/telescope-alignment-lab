# 望遠鏡校準練習室

繁體中文互動教學：選定遠方標的，在主望遠鏡與尋星鏡的倒像視野中，完成解除固定、三點校準、鎖緊與檢查。

## 操作

1. 選擇樹梢、教堂尖頂或水塔頂端。主鏡自動將指定位置置中。
2. A、B、C 各有自己的同軸固定螺帽；先將要調整的那一組固定螺帽向外轉 ¼ 圈。
3. 調整 A（上方）、B（左下）、C（右下）螺絲；必要時啟用每次四分之一格的精細調整。
4. 標的置中後，三組固定螺帽全部向內轉至鎖緊，再按「檢查對準」。

兩個光學視野都會旋轉 180°，呈現上下、左右顛倒的倒像。戶外選景仍為正常方向。十字線固定，螺絲的進退會同步改變尋星鏡景色與調整座示意。

## GitHub Pages

此專案是純靜態 HTML、CSS、JavaScript，不需要安裝套件或設定密鑰。

網站內容位於儲存庫根目錄。在 Settings → Pages 選擇 Deploy from a branch，分支 main、資料夾 /(root)。推送更新後會自動發布。

離線使用可直接開啟 `index.html`，並保留同目錄下的 `app.js`、`style.css` 和 `landscape.png`。

## 教學模型

這是尋星鏡與主鏡的指向對準，不是主鏡或副鏡的光學準直。三顆螺絲使用相隔 120° 的線性向量模型，每組搭配同軸固定螺帽；刻度不是實際圈數或角度。實際器材的結構、螺絲反應及成像方向依型號而異。

場景圖片為本專案生成。螺絲端面示意依使用者提供的參考圖重新設計。


## 手機版

手機開啟時自動採橫向版面，依可用螢幕大小配置雙視野與控制區。直向握持時網頁會旋轉 90°；可橫向握持閱讀。全螢幕按鈕會在瀏覽器支援時請求全螢幕與橫向鎖定，不支援時維持版面旋轉。控制區可獨立捲動，雙視野保持可見。

固定螺帽套在各自調整螺絲的螺桿上。鬆開某組只解除該組的鎖定；轉動螺帽不改變視野。轉動調整螺絲時改變該組刻度與尋星鏡方向，最後三組都必須鎖緊才可驗收。
